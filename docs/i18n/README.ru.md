# stealthlingo

[English](../../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | **Русский** | [Tiếng Việt](README.vi.md)

Инструмент для изучения языков, рассчитанный на терминал и незаметные занятия.

StealthLingo — небольшая консольная программа на Rust для тренировки словарного запаса в свободные минуты: найдите слово, сохраните его и проходите 3–5-минутные сессии с карточками, правописанием или диктантом на слух. Словарные данные берутся из английского [Викисловаря (Wiktionary)](https://en.wiktionary.org/) через официальный API Wikimedia, ключ не нужен; расписание повторений, проверка ответов и ваш прогресс хранятся в локальной базе данных SQLite, поэтому сохранённые слова можно повторять без интернета.

В v0.1 поддерживается изучение только английского языка.

## Установка

Готовые сборки для Windows (x64), macOS (Intel и Apple silicon) и Linux (x64 и ARM64) лежат на [странице Releases](https://github.com/viys/stealthlingo/releases); Rust не нужен. Установщики помещают `stealthlingo` и вспомогательную программу для ссылок `stealthlingo-link` в `~/.cargo/bin` и добавляют эту папку в `PATH`.

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/viys/stealthlingo/releases/latest/download/stealthlingo-installer.ps1 | iex"
```

macOS и Linux:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/viys/stealthlingo/releases/latest/download/stealthlingo-installer.sh | sh
```

Или скачайте архив для своей системы со страницы Releases, распакуйте его и держите `stealthlingo` и `stealthlingo-link` в одной папке. В Linux для воспроизведения звука используется ALSA (`libasound2`), которая по умолчанию есть в настольных дистрибутивах.

### Сборка из исходников

Нужен свежий стабильный набор инструментов Rust (1.88+) и компилятор C (SQLite встроен).

```bash
cargo install --git https://github.com/viys/stealthlingo
# или из локального клона репозитория
cargo install --path .
cargo run -- --help
```

Для сборки в Linux также нужен пакет разработки ALSA (например, `libasound2-dev`).

## Быстрый старт

```bash
stealthlingo lookup ephemeral                 # произношение и основные значения (--all — всё)
stealthlingo add ephemeral --note мимолётный  # сохранить слово с личной заметкой (необязательно)
stealthlingo                                  # открыть полноэкранное приложение: практика, поиск, список слов, статистика
```

## Полноэкранный интерфейс

В терминале команды `stealthlingo`, `study` и `review` открывают полноэкранный интерфейс. На главном экране видно, что нужно повторить сегодня, и меню (`r` повторение, `s` карточки, `p` правописание, `l` аудирование, `/` поиск слова, `w` список слов, `t` статистика, `q` выход); также работают `↑`/`↓` (или `k`/`j`) и `Enter`. Списки и длинные страницы прокручиваются теми же клавишами.

- **Esc мгновенно скрывает всё** и показывает оболочку, из которой вы запустили программу; нажмите Esc ещё раз, чтобы вернуться. Пока интерфейс скрыт, таймер сессии стоит на паузе.
- **Карточкам** не нужен Enter: `Space` показывает ответ, `1`–`4` — оценка, `a` воспроизводит слово, `s` пропускает, `q` завершает сессию.
- **Акценты**: `a` сначала воспроизводит акцент по умолчанию (настройка `accent`); повторное нажатие на том же слове воспроизводит другой записанный акцент и так далее. В нижней строке показано, какой акцент будет следующим, в верхней — какой звучит сейчас.
- **Правописание и аудирование**: введите слово и нажмите `Enter`. `Tab` показывает ответ, `Ctrl+N` пропускает слово. В аудировании `Enter` на пустой строке повторяет запись, а `Ctrl+R` воспроизводит другой акцент. При ошибке видно, какие буквы были лишними или пропущены.
- **Список слов**: `/` — фильтр, `Enter` открывает сохранённую статью (без интернета), `a` воспроизводит слово, `n` редактирует заметку, `d`, а затем `y` удаляет слово (если сохранить его снова, прогресс восстановится). `PgUp`/`PgDn` и `g`/`G` помогают перемещаться по длинным спискам.
- **Поиск слова**: введите слово и нажмите `Enter`; затем `s` сохраняет или удаляет его, `Tab` переключает краткую и полную статью, `/` начинает новый поиск, `q` возвращает назад.
- `Ctrl+C` завершает текущую сессию, отменяет фильтр или редактирование заметки, а в остальных случаях закрывает программу. Каждый ответ сохраняется сразу.
- Интерфейсу нужен терминал размером не меньше 40×12 символов. В низких окнах рамки сжимаются, сводка на главном экране умещается в одну строку, а меню прокручивается, так что выбранный пункт и поле ответа всегда видны.

С `--plain` (или когда ввод/вывод не является терминалом, например при использовании конвейера) используются построчные запросы, описанные ниже. `NO_COLOR` отключает цвета.

## Команды

| Команда | Что делает |
|---|---|
| `stealthlingo` | Открывает полноэкранное приложение. С `--plain`: повторяет слова, срок которых наступил; если таких нет — изучает новые; при пустом списке объясняет, с чего начать |
| `lookup <WORD> [--all]` | Запрос к Wiktionary (обновляет кэш; без интернета показывает сохранённую копию) |
| `add <WORD> [--note TEXT]` | Сохраняет слово. Повторное сохранение безвредно; `--note` обновляет заметку |
| `remove <WORD>` | Удаляет слово из списка (кэш словаря и история ответов сохраняются) |
| `words` | Список сохранённых слов со статусом и сроком повторения |
| `search <QUERY>` | Поиск по сохранённым словам и заметкам |
| `study [--mode memory\|spelling\|listening] [--minutes N] [--count N]` | Учебная сессия |
| `review [--count N] [--minutes N]` | Повторение карточками только тех слов, срок которых наступил |
| `stats` | Сохранённые слова по статусам, число слов к повторению, ответы за сегодня и за всё время с точностью, следующее повторение |
| `audio <WORD> [--accent uk\|us]` | Воспроизводит произношение (по умолчанию — согласно настройке `accent`) |
| `config` / `config set <KEY> <VALUE>` | Показывает или меняет настройки и расположение данных |
| `links [status\|install\|uninstall]` | Ctrl+щелчок в выводе `lookup` воспроизводит произношение и добавляет или удаляет слово (Windows) |
| `export <PATH>` / `import <PATH>` | `.json` — полная резервная копия, `.csv` — список слов |

Без `--minutes` и `--count` сессия длится `default_minutes` (5) минут.

`lookup` выводит произношения в одну строку: сначала британское (UK), затем американское (US) (`Pronunciation: UK /njuː/ · US /nu/`), и указывает акцент записи, которую воспроизводит `audio` (или предлагает `--accent uk|us`, если есть обе). По умолчанию затем показываются первые три значения не более чем трёх частей речи. `lookup --all` (или `-a`) показывает все значения с примерами, синонимами, антонимами и источником. Значения переносятся по ширине терминала, строки продолжения выводятся с отступом.

### Кликабельный поиск (Windows)

```bash
stealthlingo links install   # один раз после установки
```

Эта команда регистрирует для вашего пользователя обработчик ссылок `stealthlingo://` (права администратора не нужны). После этого `lookup` превращает каждое произношение, у которого есть запись, в гиперссылку терминала: Ctrl+щелчок воспроизводит запись в фоне, не открывая браузер или окно. Последняя строка становится `+ Add to word list`, а для сохранённых слов — `Saved in your word list · Remove`; Ctrl+щелчок по ней добавляет или удаляет слово без ввода команды (запустите `lookup` снова, чтобы увидеть изменения). Поскольку такие ссылки могут открывать и другие программы, удаление по ссылке сохраняет прогресс слова: если добавить его снова, по ссылке или через `add`, прогресс восстановится. Команда `remove`, наоборот, начинает изучение слова заново. Это работает в терминалах, которые отображают гиперссылки (Windows Terminal, VS Code / Cursor); в остальных `lookup` выводит обычный текст с командами `add` и `audio`. `links status` показывает результат определения, `FORCE_HYPERLINK=1` (или `0`) переопределяет его, а `links uninstall` удаляет обработчик. Ошибки записываются в `link-errors.log` в каталоге данных.

### Режимы обучения

Клавиши ниже относятся к построчным запросам (`--plain`); в полноэкранном интерфейсе используются одиночные клавиши, описанные выше.

- **memory (запоминание)**: посмотрите на слово, нажмите Enter, чтобы увидеть значение, и оцените себя: `1` Again (ещё раз), `2` Hard (трудно), `3` Good (хорошо), `4` Easy (легко). `a` воспроизводит слово.
- **spelling (правописание)**: прочитайте определение (само слово в определениях и примерах скрыто) и введите слово. `?` — сдаться и увидеть ответ.
- **listening (аудирование)**: прослушайте произношение и введите слово. `r` — повторить. Используются только слова с аудиозаписью произношения.

Во всех режимах `s` пропускает текущее слово, не записывая ответ, а `q` завершает сессию. Ctrl+C тоже завершает сессию; повторное нажатие Ctrl+C сразу закрывает программу. Каждый отправленный ответ сохраняется немедленно, поэтому при выходе выполненная работа не теряется, а вопрос без ответа никогда не засчитывается как ошибка.

Проверка ответа не учитывает регистр и пробелы в начале и в конце, но апострофы и дефисы важны (`well-being` — не то же самое, что `wellbeing`).

### Расписание повторений

Когда слово вернётся, решает упрощённый алгоритм SM-2:

- **Again**: через 10 минут; прогресс сбрасывается.
- **Hard**: интервал короче обычного.
- **Good**: 1 день, затем 3 дня, дальше интервал растёт с коэффициентом лёгкости (ease factor) слова.
- **Easy**: более длинный интервал, и в дальнейшем слово считается более лёгким.

В правописании и аудировании правильный ответ засчитывается как Good, неправильный — как Again. Слово с ошибкой ещё раз появится в конце той же сессии. Повторения всегда идут раньше новых слов, а в день вводится не больше `daily_new_limit` (по умолчанию 10) ещё не изученных слов. Слова с интервалом 21 день и больше отмечаются как `mastered` (выучено).

## Настройка

```bash
stealthlingo config set daily_new_limit 15
stealthlingo config set default_minutes 3
stealthlingo config set http_timeout_secs 10
stealthlingo config set accent us        # сначала воспроизводить американские записи (по умолчанию: uk)
```

Если слово записано только в одном акценте, всегда воспроизводится эта запись.

### Словарь

StealthLingo использует официальный API Wiktionary от Wikimedia: определения и примеры берутся из REST API, а МФА (IPA) с пометкой акцента, синонимы, антонимы и записи с Wikimedia Commons (OGG) — из исходного текста страницы. Если введённая форма отличается от заглавного слова словаря (`Ephemeral` и `ephemeral`), введённая форма запоминается, поэтому `add` и `remove` относятся к одному и тому же сохранённому слову.

Сборки для разработки до выхода v0.1.0 могли также использовать Free Dictionary API или Merriam-Webster. Слова, закэшированные из этих источников, по-прежнему доступны без интернета и при следующем поиске заменяются данными Wiktionary (прогресс и заметки сохраняются). Их старые настройки в `config.json` игнорируются.

## Каталог данных

`stealthlingo config` выводит точные пути. По умолчанию:

| ОС | Расположение |
|---|---|
| Windows | `%APPDATA%\stealthlingo\data` |
| macOS | `~/Library/Application Support/stealthlingo` |
| Linux | `~/.local/share/stealthlingo` |

Задайте `STEALTHLINGO_HOME`, чтобы использовать другой каталог (удобно для портативной установки или экспериментов). В нём находятся `stealthlingo.db` (SQLite с версионированными миграциями), `config.json` и `audio/` (скачанные файлы произношения).

### Резервные копии и списки слов

```bash
stealthlingo export backup.json   # всё: кэш, прогресс, история ответов
stealthlingo import backup.json   # слияние; повторный импорт того же файла ничего не меняет
stealthlingo export words.csv     # word, note, status, due_at, definition
stealthlingo import examples/words.csv   # столбец "word" (или первый столбец); "note" необязателен
```

Если при импорте JSON одно и то же слово есть с обеих сторон, побеждает прогресс с более поздним повторением. Импорт CSV ищет каждое слово, которого ещё нет в кэше, поэтому ему нужен интернет.

## Работа без интернета

- Обучение, повторение, `words`, `search` и `stats` никогда не обращаются к сети.
- `lookup` обновляет данные из Wiktionary, а если он недоступен, показывает кэшированную копию.
- `add` и `audio` по возможности используют кэш и выходят в сеть только для новых слов.
- Аудио произношения скачивается при первом воспроизведении и затем используется повторно.

## О словарных данных

- У статей указаны URL источника и лицензия, их показывает `lookup --all`. Содержимое Wiktionary распространяется по лицензии CC BY-SA 4.0.
- Полнота данных зависит от слова: транскрипция, аудио, примеры, синонимы и антонимы могут отсутствовать. StealthLingo считает все поля необязательными; слова без аудио пропускаются в аудировании.
- Wiktionary — не сервис перевода. Подсказки на русском (или любом другом языке) берутся из вашей собственной `--note`, а не из словаря.
- Сервис бесплатный и может работать медленно или быть недоступен. Соблюдайте условия использования Wikimedia и не распространяйте кэшированные данные массово без соблюдения лицензии.

## Разработка

```bash
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
```

Код разделён на `dictionary` (клиент Wiktionary и парсеры, преобразующие данные в модель `Entry`, а также декодер для данных, закэшированных сборками до релиза), `storage` (SQLite), `learning` (расписание, проверка ответов, сессии), `audio`, `commands` и `tui` (полноэкранный интерфейс на ratatui). Оба интерфейса используют один и тот же `learning::session::Session`. Расписание — чистая функция с отдельными тестами в `tests/scheduling_tests.rs`.

### Выпуск релизов

Релизы собираются с помощью [dist](https://github.com/axodotdev/cargo-dist) (`dist-workspace.toml`, `.github/workflows/release.yml`). Увеличьте `version` в `Cargo.toml`, сделайте коммит и отправьте соответствующий тег:

```bash
git tag v0.2.0
git push origin v0.2.0
```

После этого GitHub Actions соберёт программу для всех платформ и опубликует архивы и установщики как GitHub Release. `dist plan` показывает, что будет собрано; после изменения `dist-workspace.toml` выполните `dist generate`, чтобы обновить workflow.
